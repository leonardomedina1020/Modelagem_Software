# Constituição do Projeto

1. Utilizar Python 3.14 e pytest para todos os testes.
2. Manter o código simples, sem dependências externas desnecessárias.
3. Implementar exclusivamente funcionalidades previstas na especificação.
4. Escrever e executar os testes antes da implementação (TDD).
5. Garantir rastreabilidade entre requisitos, testes e código.
6. Não alterar requisitos implicitamente para fazer os testes passarem.
7. Manter especificação, testes e implementação sincronizados.
